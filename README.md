ADEMOLA — WhatsApp Bot
===========================

Version 2.2.0 | Node >= 18.0.0 | License: ISC

237 commands in 24 categories. AI chatbot, downloader, group manager,
sticker maker, text effects, audio editor, and more.


FEATURES
--------

AI & Chat       — GPT, Gemini, Copilot, Venice AI, Sora, Creart
Downloader      — YouTube, Spotify, TikTok, Instagram, Facebook, Mega, MediaFire
Fun & Games     — TicTacToe, Truth/Dare, Memes, Quotes, Anime GIFs
Group Manager   — Promote/Demote, Kick, Warn, Anti-Link, Welcome/Goodbye
Utilities       — Translate, Screenshot, URL Shortener, Web ZIP, Stalker
Media & Stickers — Sticker Maker, Emoji Mix, GIF Search, ViewOnce Reveal
Audio Editor    — Bass Boost, Nightcore, Robot, Slow/Fast, Reverse
Image Effects   — Filters, Memes, Social Mockups, Profile Pic Effects
Text Effects    — 19 styles: Neon, Fire, Glitch, Matrix, Blackpink
Security        — Anti-Call, Anti-Delete, Anti-Link, PM Blocker
Auto Features   — Auto-Reply, Auto-Read, Auto-Typing, Auto-Status
Owner Tools     — Sudo Users, Ban/Unban, Session Backup, Settings


QUICK START
-----------

1. Install dependencies:
   npm install --legacy-peer-deps


   npm start


AUTHENTICATION

COMMANDS
--------

  .menu              — Show main menu with categories
  .menu ai           — Show AI commands
  .menu download     — Show download commands
  .menu fun          — Show fun and games
  .menu group        — Show group management
  .menu tools        — Show utilities and tools
  .menu media        — Show media and sticker commands
  .menu settings     — Show bot settings
  .menu text         — Show text effects
  .menu image        — Show image filters

  .ping              — Check bot response speedz
  .alive             — Show bot status and system info
  .owner             — Send owner contact card
  .autoreply on/off  — Auto-reply when away
  .mode public/private — Toggle bot access
